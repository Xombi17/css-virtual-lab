Aim and Objectives

Aim: To simulate and analyze normal network traffic, Denial of Service (DoS), and Distributed Denial of Service (DDoS) scenarios to understand how data packets travel from client computers to a server and how excessive traffic affects server capacity and availability.

Learning Objectives

  1. Understand how legitimate network traffic travels from a client computer to a destination server.
  2. Understand server capacity and how incoming requests are accepted or dropped.
  3. Compare normal traffic, single-source DoS traffic, and multiple-source DDoS traffic.
  4. Visualize traffic flow and observe the results of different traffic scenarios using the interactive simulation.
  5. Understand how excessive traffic can overload a server and affect service availability.
  6. Learn about basic mitigation techniques, such as rate limiting and traffic filtering.
Expected outcome: Successfully simulate different network traffic scenarios, interpret incoming, accepted, and dropped request rates, and explain how excessive traffic can affect server performance and availability.

EXPERIMENT 02

Theory

1. Network Traffic and Server Capacity

Network traffic refers to the data and requests exchanged between devices over a network. In this experiment, a client computer sends requests to a destination server. The server processes incoming requests according to its available capacity, measured in requests per second (req/sec).

2. Normal Traffic

Normal traffic consists of legitimate requests sent by users or client devices. These requests travel through the network to the destination server. When the incoming request rate remains within the server's configured capacity, all requests are accepted in this simplified model.

3. Denial of Service (DoS)

A Denial of Service (DoS) scenario involves a single simulated source generating excessive requests towards a target server. When legitimate and attack traffic exceed the server's capacity, some requests are dropped. This can reduce the availability of services for legitimate users.

4. Distributed Denial of Service (DDoS)

A Distributed Denial of Service (DDoS) scenario involves multiple sources sending requests towards the same target server. Their combined traffic can overwhelm the server's available capacity. Unlike the single-source DoS scenario, the traffic originates from several simulated sources.

5. Traffic Flow in the Simulation

The visual simulation represents traffic moving from client devices towards a destination server. In the normal scenario, legitimate traffic travels through the network switch to the server. In the DoS and DDoS scenarios, additional simulated traffic is introduced to demonstrate how the server handles the combined request load.

6. Traffic Calculation

The simulation uses the following formulas to calculate the server's response to incoming traffic:

Incoming Traffic = Legitimate Traffic + Attack Traffic
Accepted Requests = min(Incoming Traffic, Server Capacity)
Dropped Requests = Incoming Traffic − Accepted Requests

7. Example Calculation

Suppose legitimate traffic is 20 requests/sec, attack traffic is 120 requests/sec, and server capacity is 100 requests/sec.

Incoming = 20 + 120 = 140 requests/sec
Accepted = min(140, 100) = 100 requests/sec
Dropped = 140 − 100 = 40 requests/sec
Observation: When incoming traffic exceeds the configured server capacity, the model accepts requests up to that capacity and drops the remaining requests. This illustrates how excessive traffic can affect service availability.

This is an educational mathematical and visual simulation. It does not transmit real network packets or generate actual DoS/DDoS attacks.

EXPERIMENT 03

Procedure

Steps to Perform the Experiment

  1. Open the Interactive Simulation section of the virtual lab.
  2. Enter the legitimate traffic rate and server capacity in requests per second.
  3. Select a scenario: Normal, DoS, or DDoS.
  4. For DoS, configure the attack request rate. For DDoS, configure the number of simulated sources and the request rate per source.
  5. Click Run Simulation to execute the selected scenario.
  6. Observe the visual representation of traffic travelling from the client or simulated sources towards the destination server.
  7. Examine the incoming, accepted, and dropped request rates, along with the server status and capacity.
  8. Repeat the experiment with different input values and compare the results for all three scenarios.
  9. Complete the assessment to check your understanding of network traffic and server capacity.
Suggested starting values: Set legitimate traffic to 20 requests/sec and server capacity to 100 requests/sec. For Normal traffic, the expected result is 20 incoming, 20 accepted, and 0 dropped requests per second.

Expected Results

  • Normal: When incoming traffic is within capacity, all requests are accepted.
  • DoS: Additional traffic from one simulated source may exceed capacity, causing requests to be dropped.
  • DDoS: Traffic from multiple simulated sources is combined and may exceed the server's capacity.

Note: This procedure uses a mathematical and visual simulation. It does not generate real attack traffic or transmit actual packets between physical computers.
