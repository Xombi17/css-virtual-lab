# REFERENCES

* **1. Internet Engineering Task Force (IETF)**
  * *RFC 4732: Internet Denial-of-Service Considerations*
  * Authors: M. Handley, E. Rescorla, IAB
  * **Link:** [https://datatracker.ietf.org/doc/html/rfc4732](https://datatracker.ietf.org/doc/html/rfc4732)

* **2. Cloudflare Learning Center**
  * *What is a Distributed Denial of Service (DDoS) Attack?*
  * Comprehensive guide to Layer 3, Layer 4, and Layer 7 volumetric attacks and mitigation techniques.
  * **Link:** [https://www.cloudflare.com/learning/ddos/what-is-a-ddos-attack/](https://www.cloudflare.com/learning/ddos/what-is-a-ddos-attack/)

* **3. Cloudflare Learning Center**
  * *What is Rate Limiting? How Rate Limiting Works to Prevent Abuse*
  * In-depth analysis of per-source request limits, token bucket algorithms, and API gateway throttling.
  * **Link:** [https://www.cloudflare.com/learning/bots/what-is-rate-limiting/](https://www.cloudflare.com/learning/bots/what-is-rate-limiting/)

* **4. Stallings, William**
  * *Cryptography and Network Security: Principles and Practice* (7th Edition)
  * Publisher: Pearson Education, 2017.
  * Focus Chapters: Denial of Service Attacks, Flooding Attacks, Botnets, and Firewall Defenses.

* **5. Tanenbaum, Andrew S., and Wetherall, David J.**
  * *Computer Networks* (5th Edition)
  * Publisher: Prentice Hall / Pearson, 2011.
  * Focus Chapters: Network Layer Congestion Control, Packet Queuing, and Network Security Architecture.

* **6. Fr. Conceicao Rodrigues College of Engineering**
  * *CSS TH ISE: Virtual Lab Development Guidelines*
  * Department of Computer Engineering, Fr. CRCE Bandra, Mumbai (Autonomous College affiliated to University of Mumbai), October 2026.
